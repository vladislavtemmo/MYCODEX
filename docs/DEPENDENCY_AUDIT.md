# MYCODEX — аудит лицензирования и зависимостей

**Статус:** предварительная техническая инвентаризация; юридическое заключение и финальный состав бинарных артефактов отсутствуют.

## Внешнее ядро

| Состав | Известно сейчас | Требуется подтвердить |
| --- | --- | --- |
| OpenVPN 3 Core | Двойное лицензирование AGPLv3 либо MPL 2.0 | Юридическая стратегия поставки SDK, модификации, notices |
| OpenSSL | Upstream документирует сборку с OpenSSL | Конкретная версия, лицензия и обновления |
| ASIO | Upstream указывает зависимость | Конкретный version pin и лицензия |
| fmt, JSONCpp, LZ4, xxHash | Указаны в официальных командах сборки upstream | Что реально линкуется, версии/лицензии/патчи |
| Прочие зависимости и tooling | Пока не установлены по дереву реальной сборки | SBOM, обязательные notices, export/privacy review |

MPL-2.0 не следует трактовать как автоматическое разрешение на произвольное закрытие изменённых файлов MPL. Не копировать код архивного OpenVPNAdapter напрямую, учитывая его AGPLv3.

До выпуска SDK: проанализировать полный результат dependency-resolution/линковки, обеспечить повторяемость и supply-chain checks, провести лицензирование с ответственным специалистом. Этот файл не юридическая консультация.
