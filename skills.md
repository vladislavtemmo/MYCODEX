# MYCODEX — инженерные компетенции и правила качества

Этот документ — внутренний регламент проекта. Он не означает, что какие-либо ChatGPT-плагины автоматически включены в других чатах.

## Требуемые компетенции

- Swift 6, Swift Concurrency, Swift Package Manager, SemVer и устойчивый публичный API.
- C/C++20, управление памятью, C ABI, сборка XCFramework и условия лицензирования.
- OpenVPN 3 Core, `.ovpn`, UDP/TCP, TLS, IPv4/IPv6, DNS, маршрутизация и MTU.
- `NetworkExtension`: `NETunnelProviderManager`, `NEPacketTunnelProvider`, `NEPacketTunnelFlow`, entitlement, lifecycle, app/extension communication.
- Keychain, защита закрытых ключей и паролей, редактирование чувствительных данных в логах.
- XCTest / Swift Testing, мок-транспорт, интеграционные и ресурсные испытания, CI на macOS.

## Правила реализации

1. Проверять доступность Apple API в целевой версии Xcode и на нужной платформе, а не по названию framework.
2. Не помещать SwiftUI в VPN-движок: интерфейс приложения является отдельным потребителем SDK.
3. Явно описывать переходы состояний: `idle`, `preparing`, `connecting`, `connected`, `reconnecting`, `disconnecting`, `failed`.
4. Управлять отменой операций, таймаутами, повторным отключением и освобождением объектов при остановке расширения.
5. Не печатать полный `.ovpn`, пароли и ключи; хранить секреты через Keychain, когда это применимо.
6. Сохранять истинные сообщения об ошибках движка без раскрытия секретов; не скрывать отсутствие native backend.
7. Фиксировать владение памятью на Swift/C границе, включать тесты несоответствующих и пустых указателей.
8. Не переносить код OpenVPNAdapter без проверки AGPL и прав использования.
9. Записывать реальные результаты тестов с платформой и компилятором; никаких фиктивных «Xcode PASS».
10. Документация, заметки, обсуждения и технические решения — на русском; имена API — на английском.

## Критерии завершения задачи

- Поведение и сценарии ошибок определены.
- Добавлены тесты на изменённую логику и пройден соответствующий тестовый прогон.
- Указана реальная проверенная платформа/компилятор и не проверенные среды.
- Обновлены `PROGRESS.md`, по необходимости `memory.md`, `docs/ARCHITECTURE.md` и `docs/ROADMAP.md`.
- Указаны ссылка на коммит/PR **либо** причина, почему публикация не состоялась.

## Команды проверки

```bash
swift package describe
swift build
swift test
swift build -c release
```

Для реальной Apple-интеграции дополнительно нужны сборка в Xcode с правильными destination, подписи, Network Extension entitlement и тесты на устройствах. Выполнение команд выше само по себе не доказывает работоспособность туннеля.
